# Marstek Venus E 3.0: автоматика заряду і дашборд

Агент на Android-планшеті керує станцією через локальне Open API, а дашборд на GitHub Pages відкривається з iPhone чи будь-якого браузера.

**Що вміє**

- Вдень заряджає до 50%, у нічний тариф до 100%.
- Читає графік ВОЕ для твоєї черги. Перед відключенням від 3 годин заздалегідь заряджає до 80%, а якщо за прогнозом споживання цього мало, то вище.
- Стежить за температурою батареї. Від 45 °C знижує потужність заряду вдвічі, від 52 °C зупиняє примусовий заряд і надсилає сповіщення. Сповіщає і про низьку температуру (5 °C і нижче).
- Сам помічає зникнення і появу світла, рахує витрачені Вт·год і вчиться на твоєму реальному споживанні.
- Telegram: сповіщення і команди. Дашборд: стан, графіки, графік відключень, кнопки і налаштування.

**Як це влаштовано**

```
iPhone (дашборд) ──┐
                   ├── приватний GitHub Gist ── планшет (агент) ── Wi-Fi роутер ── станція
Telegram ──────────┘
```

Станція в інтернет не виходить. Агент спілкується з нею тільки в домашній мережі, а назовні сам надсилає дані в приватний Gist і забирає звідти твої команди. Порти на роутері відкривати не треба.

---

## Крок 1. Станція і роутер

1. У додатку Marstek онови прошивку станції. Потрібна Control v144 або новіша, краще 150+.
2. У додатку Marstek увімкни **Open API** (Local API) і залиш порт **30000**.
3. Закріпи за станцією постійну IP-адресу. На Xiaomi 4A це робиться в адмінці роутера (`192.168.31.1`) у розділі прив'язки IP до MAC-адреси (DHCP static / Bind IP and MAC) або в додатку Mi WiFi у налаштуваннях мережі. Вибери станцію зі списку пристроїв, збережи і запиши адресу.
4. Роутер і планшет мають живитися від виходу станції, інакше під час відключення агент втратить зв'язок.

## Крок 2. GitHub: репозиторій, сторінка і токен

Зручніше з комп'ютера.

1. Зареєструйся на github.com, якщо ще немає акаунта.
2. Справа вгорі «+» → **New repository**. Назва `marstek-control`, тип **Public**, решту не чіпай → **Create repository**.
3. На сторінці репозиторію натисни **uploading an existing file**. Розпакуй архів і перетягни у вікно **весь вміст** папки `marstek-control` (файл `index.html`, папки `agent`, `icons`, `vendor` і решту). Внизу **Commit changes**.
4. Увімкни сайт: **Settings** → **Pages** → у Source вибери **Deploy from a branch**, гілка **main**, папка **/(root)** → **Save**. За 1-2 хвилини дашборд з'явиться за адресою `https://ТВІЙ_ЛОГІН.github.io/marstek-control/`.
5. Створи токен: клік по аватарці → **Settings** → внизу зліва **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**.
   - Note: `marstek`
   - Expiration: **No expiration** (або рік, тоді не забудь оновити)
   - Постав галочку **лише gist**, більше нічого
   - **Generate token** і одразу скопіюй його (`ghp_...`). Повторно GitHub його не покаже.

Токен дає доступ тільки до твоїх gist-нотаток, до репозиторіїв і акаунта він доступу не має. Репозиторій публічний, але секретів у ньому немає: токени зберігаються лише на планшеті і в браузері iPhone.

## Крок 3. Telegram-бот

1. У Telegram відкрий **@BotFather** → `/newbot` → придумай назву і логін (закінчується на `bot`).
2. Скопіюй токен вигляду `123456789:AA...`.
3. Відкрий свого бота і натисни **Start**.

## Крок 4. Планшет (агент)

1. Встанови з **F-Droid** (не з Play Market, там застарілі версії) два додатки: **Termux** і **Termux:Boot**. Відкрий Termux:Boot один раз, щоб він зареєструвався.
2. Відкрий Termux і по черзі виконай:

```sh
pkg update -y && pkg install -y python git
git clone https://github.com/ТВІЙ_ЛОГІН/marstek-control
cd marstek-control/agent
python agent.py --setup
```

Майстер спитає IP станції (спробує знайти сам), твою чергу ВОЕ (наприклад `3.1`), токен GitHub і токен Telegram. На кроці Telegram він попросить написати боту будь-яке повідомлення і сам визначить chat_id.

3. Перевір зв'язок:

```sh
python agent.py --test
```

Має бути «OK» біля станції, графіка, GitHub і Telegram, а час з поясом UTC+2. Якщо там UTC+0, вистав у налаштуваннях Android часовий пояс Київ.

4. Перший запуск з перевіркою напрямку заряду:

```sh
python agent.py
```

Напиши боту `/charge 100` і через хвилину подивись у додатку Marstek: станція має **заряджатися** від мережі. Якщо натомість вона віддає енергію, агент через кілька хвилин сам вимкне автоматику і повідомить, але краще не чекати. Тоді зупини його (Ctrl+C у Termux, клавіша CTRL на панелі над клавіатурою), відкрий `nano config.json`, додай рядок `"charge_sign": 1,` і запусти знову. Після перевірки напиши `/auto`.

5. Запуск у фоні і автозапуск після перезавантаження:

```sh
nohup sh start.sh > /dev/null 2>&1 &
mkdir -p ~/.termux/boot && ln -sf ~/marstek-control/agent/start.sh ~/.termux/boot/marstek
```

6. Налаштування Android, щоб система не вбивала агента:
   - Налаштування → Додатки → Termux і Termux:Boot → Батарея → **Без обмежень**.
   - Android 12 і новіші: увімкни «Для розробників» (7 разів тапни номер збірки) і там увімкни **«Вимкнути обмеження дочірніх процесів»** (Disable child process restrictions), якщо такий пункт є.
   - Планшет тримай на зарядці від станції, екран може бути вимкнений.

## Крок 5. iPhone

1. Відкрий у **Safari** `https://ТВІЙ_ЛОГІН.github.io/marstek-control/`.
2. Кнопка «Поділитися» → **«На початковий екран»** → «Додати». З'явиться іконка «Станція».
3. Відкрий дашборд саме з цієї іконки (у iOS у неї окреме сховище, тому токен вводиться вже в ній).
4. Встав той самий токен GitHub → **Підключити**. Щоб перенести токен з комп'ютера, найпростіше надіслати його собі в «Збережене» в Telegram, вставити і одразу видалити повідомлення.

Так само дашборд відкривається на будь-якому комп'ютері чи телефоні.

## Крок 6. Обов'язкова перевірка резерву

Коли агент працює, вимкни автомат, від якого живиться вхід станції (або витягни її вилку з розетки).

- Квартира має й далі живитися від станції, а в Telegram за хвилину прийде «Світло зникло».
- Увімкни автомат назад, має прийти «Світло повернулось».

Якщо при цьому живлення споживачів пропало, у дашборді відкрий **Налаштування** → **Режим утримання** і вибери **UPS** (або **Auto**), збережи і повтори перевірку.

## Як користуватися

**Дашборд.** Заряд, температура, навантаження, наявність світла, рішення автоматики і його причина, «вистачить на» для різного споживання, графік відключень на сьогодні і завтра, історія за 1/6/24 години, журнал відключень і сповіщень. Команди з дашборда виконуються протягом хвилини. Дані оновлюються щохвилини, поки дашборд відкритий, і раз на 15 хвилин, коли закритий.

**Кнопки.** Перемикач автоматики (вимкнена автоматика повертає станцію в Auto). «Зарядити вручну до» 60/80/90/100% діє, доки не натиснеш «Скинути».

**Налаштування в дашборді.** Цілі вдень, вночі і перед відключенням, з якої тривалості відключення вважати довгим, години нічного тарифу, потужність заряду, черга ВОЕ, пороги температури, поріг сповіщення про низький заряд, режим утримання.

**Telegram.**

| Команда | Дія |
|---|---|
| `/status` | стан станції |
| `/temp` | температура і пороги |
| `/outages` | графік відключень твоєї черги |
| `/charge 90` | зарядити до 90% |
| `/auto` | скинути ручну ціль |
| `/on`, `/off` | увімкнути або вимкнути автоматику |

**Сповіщення приходять про:** висока, критична і низька температура (і коли вона повернулась у норму), зникнення і появу світла з витраченою енергією, низький заряд під час відключення, втрату зв'язку зі станцією, зміну режиму заряду, команди з дашборда.

## Температура

| Рівень | Поріг | Що робить агент |
|---|---|---|
| Норма | до 45 °C | працює як звичайно |
| Висока | від 45 °C | заряд на половині потужності, сповіщення, нагадування раз на 2 години |
| Критична | від 52 °C | примусовий заряд зупинено, сповіщення кожні 30 хв |
| Низька | 5 °C і нижче | сповіщення (при 0 °C станція сама не заряджається) |

Повернення в норму відбувається з запасом 3 °C, щоб сповіщення не сипались при коливаннях. Пороги змінюються в налаштуваннях дашборда. Виробник вказує робочий діапазон станції від -20 до +60 °C, тому 45/52 °C залишають запас.

## Обслуговування

```sh
cd ~/marstek-control/agent
tail -f agent.log        # журнал у реальному часі (вихід Ctrl+C)
sh stop.sh               # зупинити
nohup sh start.sh > /dev/null 2>&1 &   # запустити
sh update.sh             # оновити код з GitHub і перезапустити
python agent.py --test   # перевірка зв'язку
```

Якщо ти змінив файли в репозиторії GitHub (наприклад, нову версію агента), на планшеті достатньо `sh update.sh`.

## Якщо щось не працює

- **«Станція не відповідає».** Перевір, що Open API увімкнено в додатку Marstek, IP не змінився, планшет і станція в одній Wi-Fi мережі (не в гостьовій).
- **Дашборд пише «Дані агента не знайдено».** Агент ще жодного разу не підключився до GitHub. Запусти `python agent.py --test` і перевір рядок GitHub.
- **«Агент не на зв'язку».** Планшет вимкнений, без інтернету або Android зупинив Termux. Перевір налаштування батареї з кроку 4.
- **Графік не завантажується.** Графік береться з відкритого проєкту [gpv-voe-vinnytsia](https://github.com/vn-progr/gpv-voe-vinnytsia), який оновлює дані з e-svitlo кожні 10 хвилин. Якщо він зупиниться, агент працюватиме за тарифами, а графік можна буде підключити з іншого джерела через `schedule_url` у `config.json`.
- **Неправильні години відключень.** Перевір чергу в налаштуваннях і часовий пояс планшета.

## Додаткові параметри `config.json`

Змінюються на планшеті через `nano config.json`, після зміни перезапусти агента.

| Параметр | За замовчуванням | Опис |
|---|---|---|
| `charge_sign` | `-1` | знак потужності заряду в Passive-режимі |
| `capacity_wh` | `5120` | ємність батареї |
| `min_soc` | `12` | нижня межа розряду (DOD 88%) |
| `reserve_pct` | `10` | запас понад прогноз перед відключенням |
| `prep_margin_min` | `30` | на скільки хвилин раніше закінчити заряд перед відключенням |
| `default_load_w` | `250` | стартове споживання для прогнозу, далі агент вчиться сам |
| `push_live_sec` / `push_idle_sec` | `60` / `900` | як часто оновлювати дашборд, коли він відкритий і закритий |
